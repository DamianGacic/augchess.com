# old_design

Archive of replaced artwork — nothing here is loaded by the game.

- `figures/` — previous figure images from `figures/images/`
- `icons/` — previous icons from `figures/icons/`, `augments/icons/`, `assets/`

Before replacing a design, copy the current file here as
`<id>-v<N>-<variant>.<ext>` (v1 = oldest). See ../project.md.
