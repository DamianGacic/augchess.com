# Project notes

## Keep every previous design

Whenever a figure image or an icon is replaced or redrawn, keep the old
version before overwriting it:

- Figure artwork (`figures/images/`) → `old_design/figures/`
- Icons (`figures/icons/`, `augments/icons/`, `assets/` logo/favicon) → `old_design/icons/`

Name the saved copies `<id>-v<N>-<variant>.<ext>`, numbering versions from
`v1` (oldest) upward, e.g. `old_design/figures/apprentice-v2-black.svg`.
Nothing in `old_design/` is loaded by the game — it is an archive only.
